# 器械握持：接触几何、肌肉配力与验证范围

本模块让器械通过手指和手掌的接触传递负重。器械不再作为固定在掌骨上的点质量：张手、手指未接触握把，或者肌肉与摩擦约束无法同时满足时，动作仍可查看，但不提供有效肌力或接触力。

当前支持右手、左手和双哑铃。双哑铃的输入质量是两只器械的总质量，模型将其等分为两个独立刚体。杠铃入口与计算支持已移除，包含零质量的杠铃请求也会明确拒绝；历史研究记录保留。页面恢复旧杠铃动作时会备份原记录、保留姿势和时间、清零负重并提示重新选择哑铃，不自动替换成另一种带负重的器械。`grasp.py` 负责几何和物体方程，`fullbody_solver.py` 联合求解接触与肌肉。全身模型来源和总体限制见 [FULLBODY.md](FULLBODY.md)。

## 如何使用与理解结果

先摆好肩、肘和腕，选择器械与质量，再执行握持。闭合算法只调整所选手的手指坐标，不移动上肢去迁就器械。闭合成功仅表示源接触代理与握把贴合；完成动作计算后，才能判断每帧是否能在当前模型下承重。转腕、前臂旋转和身体运动时，器械的位置与方向随真实掌骨坐标更新。

编排持续持物动作时，保持各关键帧的手指闭合，并留出合理的动作时间。手动打开手指会导致相应接触条件失效。双哑铃分别随各自手掌运动，不要求两手保持固定握距。当前功能不模拟“从桌面抓起—滑动—重新抓稳—放下”的接触切换过程，也不自动生成器械掉落动作。

| 输出 | 表示什么 |
|---|---|
| `grasp.geometryValid` | 各持物手的接触与握把净空通过几何检查 |
| `grasp.feasible: null` | 只有编辑或预览结果，尚未计算承重 |
| `grasp.feasible: true` | 该帧接触、器械、肌肉和指定外部支撑共同配平 |
| `quantitativeValid: false` | 本帧或整段动作存在失败，肌力和接触力停用 |
| `normalN`、`forceOnObject` | 通过求解时的接触法向力及手对器械的作用力，不是肌肉张力 |
| `objectResidualForceN`、`objectResidualMomentNm` | 器械合力与力矩未平衡量，用于检查数值解 |

“当前模型未找到满足约束的解”不等于“真人做不到”。源肌腱路径、接触代理、闭合指形和肌肉分担假设都会影响可行性。此次开发中，同一握把和原始肌力参数下，几何优化选择不同的合法指形，就会改变较大屈肘角度下能否配平；因此不能把某次失败直接解释成人的握力上限。

## 接触和器械如何建模

右手采用固定来源 MS-Human-700 详细右手文件中的皮肤胶囊，覆盖掌骨及各节手指。左手详细视觉文件没有这些胶囊，因此本模块将右手胶囊在对应左侧骨段坐标内镜像，明确采用左右对称假设。这些派生代理只用于接触计算，不改变原生骨骼质量、关节、肌肉最大力或源 XML。来源是 [固定版本的 MuJoCo Menagerie MS-Human-700](https://github.com/google-deepmind/mujoco_menagerie/tree/98a70c569c4c1b6da467a20012f766ee1f8dc521/ms_human_700)；原作者仓库提供详细右手操作模型及其来源说明。[MS-Human-700 原作者仓库](https://github.com/LNSGroup/MS-Human-700)

使用声明的理想器械规格，显示层直接读取同一份 `equipmentInstances[].geometry`。哑铃采用直径 28 mm 的圆柱握把；以下尺寸是本实验的设计参数，不是对某款商品的测量。

| 参数 | 哑铃 |
|---|---:|
| 杆总长 | 0.22 m |
| 杆半径 | 0.014 m |
| 配重片半径 | 0.060 m |
| 单片厚度 | 0.035 m |
| 配重片中心距器械中心 | ±0.085 m |

总质量按杆与两片环形配重的体积、统一密度分配，配重片中心孔扣除杆的体积，避免重复计算。由此得到中心质心及转动惯量。真实器械不同材料、质量分布和偏心误差尚未标定。

闭合以末节手指接触为目标，并约束所有代理避免穿入握把。接触候选的距离门槛为 0.6 mm，最大允许穿入为 0.5 mm；这些是公开的几何容差，不代表已测得皮肤压缩特性。另检查胶囊的整个轴向范围不越过配重片内侧，这是保守的净空检查。

每处接触只能推，不能拉。默认滑动摩擦系数为源 MuJoCo 模型采用的 1.0，允许在器械参数中显式更改；该值不等于人体皮肤与所有握把材料的通用实测摩擦系数。使用八条边的内接多面体近似摩擦锥，因此允许的切向力不会超出相应圆锥。点接触不提供独立的扭转力矩；物体力矩由多个接触点的力臂产生。库仑摩擦、多面体内逼近和接触力矩的定义可参阅教材原作者的 [Modern Robotics 接触与摩擦说明](https://modernrobotics.northwestern.edu/nu-gm-book-resource/12-2-1-friction/)。

## 负重如何传入手指和全身

给定骨骼轨迹后，分别计算器械质心加速度、角速度和角加速度。对每个器械要求：

```text
接触力之和 = 质量 ×（质心加速度 − 重力加速度）
接触力矩之和 = 世界坐标转动惯量 × 角加速度
               + 角速度 ×（世界坐标转动惯量 × 角速度）
```

同一接触力以相反方向施加给实际接触的掌骨或指骨，通过该点的 Jacobian 转为关节力矩。因此末节指骨的受力会进入对应 DIP、PIP、MCP 等关节方程，而不是直接绕过这些关节施加给手腕。力到广义力的映射与接触约束背景见 [MuJoCo 官方计算文档](https://mujoco.readthedocs.io/en/stable/computation/index.html)。

每帧用一个线性规划同时确定肌肉激活与手部接触摩擦锥系数，满足全身内部关节和每个器械的六维平衡；肌肉激活限于 0 到 1，沿用原生主动、被动及力速能力。目标为最小激活之和，接触系数的极小代价用于避免多余的内力。它是一种明确的分担假设，不是唯一人体招募策略。相关肌骨握持研究也采用抓握矩阵、摩擦锥与肌肉优化，但本实现没有继承该研究的人体验证结论。[精细握持姿势与肌肉努力优化原研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC9345905/)

带载手的指关节不使用关节止挡来代替握紧，以免边界反力提供没有肌肉能力约束的夹持。其他关节仍沿用原实验的合法止挡规则。骨盆支架或足底支撑只承担已声明的外部支撑：器械等效质心力和转矩用于整体支撑核对，不再重复加入内部关节负荷。足底仍沿用既有根部平衡分配，没有改为手、足和肌肉接触全部同时优化。

持续接触还需满足手部与器械接触点的相对速度、相对加速度检查，门槛分别为 `1e-4 m/s` 和 `0.01 m/s²`。失败解的力值被清空；残差与几何保留，便于判断问题。没有用保留力矩、理想手腕附件或任意新增执行器补齐失败解。

## 接口与复算

`grasp.attach(payload)` 接受 `{q, loadKg, hand, equipment}`；器械对象也可以给出 `massKg`、`hand`，两处质量必须一致。它返回只改所选手指的 `q`、`changedCoordinates`、`grasp` 与 `equipmentInstances`。失败时返回原姿势。`grasp.describe(ctx, data, scene)` 不重新优化，供姿势编辑和预览快速更新几何状态。显示矩阵使用 Three.js 列优先布局，器械中心为原点、杆轴为局部 Z 轴。

本地桥接入口是 `POST /api/fullbody/grasp`。浏览器使用当前模型的 `computationSha256` 作为请求版本依据；模型参数哈希和计算代码哈希共同标识验证版本。只改源代码、不重启进程时，不应继续复用旧验证状态。

在仓库根目录使用已有 D 盘环境：

```powershell
& ./.venv-fullbody/Scripts/python.exe -X utf8 experiments/body-lab/verify_grasp.py --out grasp-validation.json
& ./.venv-fullbody/Scripts/python.exe -X utf8 experiments/body-lab/fullbody_verify.py --api-url http://127.0.0.1:4192
& ./.venv-fullbody/Scripts/python.exe -X utf8 experiments/body-lab/verify_ground.py
```

当前握持检查覆盖左右手、双哑铃及拒绝杠铃请求；另检查张手挂载、50 kg 过载、沿杆轴存在负荷时零摩擦、开指停力、随腕转向、接触虚功和支撑质量不重复计算。历史整段示例为 2 kg、肘 0°→90°、保持、再回到 0°，85 帧；当时手指接触虚功差分误差约 `7.3e-11 Nm`，最大内部残差约 `3.5e-13 Nm`。这些历史数值衡量算法内部一致性，不是人体张力的测量误差，也不作为修改后版本已经重算的证明；当前通过状态以对应版本的实际输出报告为准。

## 仍未包含的内容

未重建完整伸肌腱膜，也没有个体化肌肉参数、皮肤面积压力、软组织弹性、扭转摩擦、器械与躯干或其他肢体的碰撞，以及真实神经激活随时间建立和释放的过程。当前输出是规定轨迹下逐帧的配力，不是带神经控制的前向持物仿真。

缺少伸肌腱膜并不禁止开展受限握持研究，但会影响远近指关节及肌肉之间的力传递。已有开放手腕模型研究报告了未完整建模伸肌腱膜时的功能任务与限制；另一项对照研究直接分析了补入腱膜网络后肌肉和关节力分担的变化。两者都不能替代本模型的后续实测标定。[手腕功能任务模型原研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC10650739/)，[伸肌腱膜力学对照研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC3986208/)
