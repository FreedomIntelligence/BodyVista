# 肌肉运动公开案例

[动作定义](scenes.json)记录每个动作的类别、中文说明、观察部位、镜头和输入姿势。原有 11 个案例绑定各自的缓存哈希。新增案例使用已登记的回归场景，或在其起始姿势上指定各时刻的关节角度。角度以度为单位，时间以秒为单位。双脚承重与骨盆支架承托分别保留在场景和动作说明中。

## 重建动作缓存

先按[资源安装说明](../RELEASE_ASSETS.md)恢复同版模型和原始缓存。在 Windows 的 D 盘项目根目录使用已安装完整依赖的 Python 环境运行：

```powershell
.venv-fullbody\Scripts\python.exe -B -X utf8 -u experiments\body-lab\showcase\build_showcase.py --keep-going
```

构建脚本以每秒 12 帧采样，每次只启动一个限用单核的低优先级求解进程。新进程在可用物理内存达到 5,100 MiB 时启动，作业内存上限为 1,536 MiB。若可用物理内存降到 4,200 MiB 以下，程序会停止当例并等待重试。每案通过完整的肌力、支撑和力矩校验后才写入缓存。哑铃动作还要通过握持与器械平衡校验。

重复运行会检查已有回执、输入和缓存哈希，接着处理剩余动作。`--case ID` 可针对一个动作重算或复核回执，`--publish-only` 可从完整回执重建合并目录。`--base-cache 路径` 用于指定含原 11 个动作的已安装缓存目录。

合并后的 `.runtime-cache/showcase-full/motion-cache/catalog.json` 与同目录下的 gzip 文件供网页和离线安装器使用。[逐案验证记录](verification.json)给出采样帧数、拥有完整 740 项肌腱力的帧数、原场景和结果的 SHA-256、缓存的 SHA-256 和压缩字节数。模型给出指定姿势、速度、支撑与负重条件下的一组可行肌力。某个单元的力值可以为零。
