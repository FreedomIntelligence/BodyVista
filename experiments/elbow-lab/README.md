# BodyVista 右臂动作实验台

本机研究版将 BodyVista 的右臂图谱与 OpenSim Arm26 模型绑定。可在图中拖动肩、肘、腕、掌，确认关键姿势，并设置相邻两帧的时长。哑铃和杠铃拖到掌心即可吸附，所有帧使用同一件器械。浏览器同步比较同一轨迹上的空手与持物：左图、虚线为空手，右图、实线为实验组。六个肌肉单元的张力（N）与激活度（0–1）可切换查看。每条曲线都是本实验条件下的模型估计。

## 在本机打开

从仓库根目录执行下面两行。本次用 Python 3.13、NumPy 2.3.3、SciPy 1.18.0 在 CPU 上实测。重新生成模型表才需要 OpenSim 4.6。服务只监听本机环回地址。

```powershell
cd experiments/elbow-lab
python -X utf8 server.py --port 4192
```

打开 [本地实验台](http://127.0.0.1:4192/experiments/elbow-lab/)。新建实验从空白序列开始。拖肩可移动整臂，拖肘可绕肩转上臂，拖腕可带动两段骨骼追随，拖掌可转腕。骨长保持固定，编辑在侧面平面内进行。点击“确认第 1 帧”，再摆下一帧，确认时输入两帧间的秒数。最后点击“生成并播放”。点击帧可修改姿势、替换、调整时长、重排或删除。方向键可微调，Shift 加大步幅。

器械可拖放，也可先选哑铃或杠铃，再点掌心。设定总重后吸附，手指会收拢，器械随手回放，可随时卸下。杠铃按右手握杆中心且承担整杆重量计算。当前器械均近似为握点的集中质量，未计杆自身的旋转惯量。上臂长 0.2904 m，肘至腕 0.24 m，腕至握点 0.06 m，视图与持物计算共用这些尺寸。

“打开屈肘示范”载入原四帧 0°、90°、90°、0°，全程 3 秒、5 kg，停在 1.50 秒水平保持。也可直接打开 [示范](http://127.0.0.1:4192/experiments/elbow-lab/?demo=1)。原实验保留为独立卡片。已有非标准半径的旧点负载在回放中显示为相应位置的小球，用户重新确认姿势后转换到掌心器械。

浏览器保存已确认姿势、器械与时长。每次改动后重新计算，力学无法求解时仍可预览动作，界面区分纯姿势预览、仅有肘净力矩、六肌张力估计，撤下无效的旧曲线。

“观察肌肉”仅列出整段张力变化超过0.01 N的单元，以最大值与最小值之差判断；空手或实验任一完整有效曲线满足即可，两条不同的恒定曲线不算变化。列表、表格按钮和模型点选遵循同一条件；无有效结果或无匹配时禁用选择。此筛选只影响曲线观察，全部六个肌肉仍参与计算，表格保留其数值。

## 三个可复算的现象

| 实验 | 设置 | 1.50 秒的结果 |
|---|---|---|
| 同一轨迹换负重 | 水平力臂 0.30 m；空手、2 kg 和 5 kg | 空手净力矩 2.728 N·m；持物相对空手分别增加 5.886、14.715 N·m。5 kg 时总计 17.443 N·m。 |
| 同一姿势主动绷紧 | 5 kg，伸肌最低激活从 0 调到 0.10 | 净力矩仍为 17.443 N·m。肱二头肌长头张力由 206.4 增至 247.0 N，肱三头肌长头由 80.5 增至 147.8 N。张力含被动分量。 |
| 只选目标姿势 | 把求解模式切为预测，交替选择偏省力与偏平稳 | 默认四帧，0.40 秒的中间角度约为 12.65° 与 28.57°；两种方案均在 1 秒到达 90°，保持到 2 秒。 |

## 如何计算

- 解剖图谱的 32 块骨网格与六块右臂肌肉网格取自仓库自带资源。绑定表核对原始 ID，并由骨端位置对齐显示旋转轴。肌肉沿原网格采样的纵向中心线形变。OpenSim 计算的纤维长度决定中段纵向收缩与相应横向增厚。屈肌采用连续位移路径，先扣除骨姿势已经造成的路径缩短，再计算剩余收缩，避免深屈肘时重复压缩、形成折角。中线使用连续三次插值，宽度轮廓平滑；伸肌沿后肘绕行。短头原网格只显示部分远端结构，完整共同肌腱与组织接触仍待进一步配准。表面细条用于说明走向，激活引起的少量横向饱满度变化是教学显示近似。整个形变未求解组织应变或碰撞力，不能由表面颜色读出局部应力。查看 [绑定清单](atlas/bindings.json) 与 [图谱第三方归属](../../THIRD_PARTY_NOTICES.md)。
- 肩腕为零位且肩根固定时，力学采用官方 Arm26 的锁肩右肘模式。六条路径的力臂、被动张力和满激活能力使用 OpenSim 生成的查找表。点负重同时增加重力矩和转动惯量。采用刚性肌腱及主动能力按激活线性缩放的近似。模型、导出方法、原始来源与直接 OpenSim 对照见 [模型说明](model/README.md)。
- 规定轨迹模式在相邻关键姿势间用五次多项式起停。逐帧求有界、满足力矩平衡且六肌激活平方和最小的解。预测模式使用相同的关键姿势、时间和停顿，改变各段中间的时间分布，并按施力或平稳程度搜索可行方案。逐帧最优分配若违反激活建立/释放速率，就对整条激活序列用线性规划修正，使兴奋始终在 0–1；这一步最小化相对静态基线的绝对偏差。预测的兴奋到激活采用简化一阶模型，时间常数取 Arm26 的 0.01/0.04 秒；它不是原始完整弹性肌腱模型。
- 逐个候选按成本排序。把输出肌肉控制送回自由肘动力学，用四阶积分从初始姿势向前推进，中途不再指定角度；负重和空手都需通过 1° 追踪阈值才能返回。导出包区分仅达到力矩约束、前向回放未测和回放失败。查表在 0–130° 范围内，微小自由角越界另报，回放未建硬止挡。该检查检验数值自洽，未提供来自真人的逐肌力验证。
- 肩、腕参与或肩根移动时，pose_dynamics.py 计算平面引导动作的肘部净力矩。包括肩平移/转动的惯性、肘转动、腕转动后的持物位置和加速度。裸手和前臂质量仍按 Arm26 合并。六肌配力使用单独的肩—肘二维表，肩与腕按外部给定轨迹引导，输出只估计肘部肌肉分担。此分支尚未完成自由前向回放验证，界面使用“按指定轨迹求力”。只要任一组无法满足肘力矩约束，整段逐肌曲线撤下，保留所需净力矩。
- 二维查表每 2° 采样肩 -70° 至 150°、肘 0° 至 130°，绑定原模型与数据 SHA256。速度能力直接取 OpenSim 路径伸长速度，包含独立肩速度和肘速度。model/extract_pose_forces.py --verify 对照原生 OpenSim，四个非格点工况最大能力差 0.247 N。显示纤维长度另由每 5° 的 model/extract_fibers.py 提取。
- 支持 2–10 个已确认关键帧，最长 10 秒，相邻至少 0.2 秒。肩角 -70° 至 150°，肘 0° 至 130°，腕 -65° 至 70°，肩点前后/上下平移各 ±0.22 m。原锁肩预测限于起停的平滑轨迹族。全身、双手共同握持、三维球关节和个体化参数尚待扩展。

## 离线复算与导出

```powershell
python -X utf8 experiment.py verify
python -X utf8 verify_pose.py
python -X utf8 experiment.py solve --kg 5 --radius 0.30 --co 0.10 --out braced.json
python -X utf8 experiment.py solve --mode predict --objective effort --out prediction.json
python -X utf8 experiment.py solve --scene your-export.json --out reproduced.json
```

[验收结果](verification.json)包含六组静力对照、拮抗比较、两种目标的控制边界和不同时间分布、失败样例。运行 `experiment.py verify --write` 会在所有检查成功后更新冻结的 [默认样例](demo.json) 与验收结果。

实时接口为 `GET /api/model`、`GET /api/demo`、`POST /api/solve`；求解输入为 JSON 实验卡，冲突或无可行目标时返回 HTTP 422。具体字段、单位与一个可重现的实例见默认样例的 `scene`。手部标记用同一固定距离和相对肘轴的前向、向下坐标，超过 1 mm 径向误差即拒绝。

纯静态回放也可从仓库根目录运行 `python -m http.server 4193 --bind 127.0.0.1`，打开 [4193 上的静态样例](http://127.0.0.1:4193/experiments/elbow-lab/)。此入口可编辑和预览新动作，只有与冻结示范匹配的输入带有已计算的张力。公共 GitHub Pages 的默认构建未作改动；可搬运的本地静态目录用 `python pack_static.py 目标目录` 单独导出。模型与第三方图谱各自的来源记录一并保留，图谱的分发范围以项目原说明为准。
