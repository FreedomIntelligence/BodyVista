# Arm26 锁肩右肘模型

本研究使用 OpenSim 官方 Arm26 的肩、肘、前臂与手参数及六个 Thelen2003 肌肉肌腱单元。实验锁定右肩，前臂与手作为一个刚体，仅保留右肘屈伸。动力学与教材中的平面负重实验相接，显示骨架可由浏览层另外绑定。计算无需 VTP 外观模型。

## 来源和署名

- 官方模型版本为 [opensim-models/Arm26，提交 84b487c](https://github.com/opensim-org/opensim-models/blob/84b487c4e3245359a64381e01f01b9cf4772d457/Models/Arm26/arm26.osim)。原始文件保存在此目录的 `arm26.osim`，SHA-256 为 `e2224d0044eb393b05d64926c3fa1682c451a9adc7f510e5517ef9958d3d41b9`。
- 原文件 credits 字段标注 [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/)。OpenSim Development Team 的 J. Reinbolt、A. Seth、A. Habib、S. Hamner 根据 Kate Holzbaur 的模型改编。本研究另从原文件导出锁肩查找表，并将重力大小由模型的 9.8066 调整为实验卡指定的 9.81 m/s²。研究依据见 [Holzbaur 等的上肢模型论文](https://doi.org/10.1007/s10439-005-3320-7)。
- 提取工具使用官方 [OpenSim 4.6 Python 包](https://pypi.org/project/opensim/4.6/)，此次运行版本为 `4.6-2026-06-22-85aaf64`。局部有效范围为原模型右肘 0° 到 130°。零位定义沿用模型。负重位于理想教学屈伸平面，以固定半径随前臂转动，90° 时其垂直重力臂等于输入半径。

## 如何由模型得到腕部负载及肌肉能力

1. 将肩部角度和速度固定为零，关闭所有肌肉施加的力，用 OpenSim 的逆动力学求裸臂重力矩与转动惯量。这个固定轴刚体系统没有速度平方项，惯量常数为 0.0704997264 kg·m²，空手在 90° 时抵抗重力需 2.7278957045 N·m。点载荷另贡献重力项 `m·g·r·sin(q)` 和惯量 `m·r²`。
2. 每隔 0.25° 调用 OpenSim 的 `computeMomentArm`，获得各条路径的有符号力臂。肩锁定使本实验不能解释肩肘协同，前臂旋前、旋后也不属于这个自由度。
3. 使用肌腱等长近似，将长度固定在各自松弛长度。根据 OpenSim 的羽状角模型计算对应肌纤维长度，取投影到肌腱方向的被动张力和单位激活、零速度时的主动能力。运行时按姿势线性插值，按 Thelen 满激活力速曲线修正主动能力。
4. 给定肌肉激活度后，本基线用 `被动张力 + 激活度 × 满激活主动能力` 估计整条单元的拉力。部分激活下的力速响应采用线性缩放，缺少原 Thelen 弹性肌腱独立状态；不能将张力解释为活体实测值。模型中保存了六条原始肌肉的激活和去激活时间常数，时间常数本身不会把逐帧静态分担变成动态兴奋控制。

## 复算

在安装 OpenSim 4.6 的 Python 环境，从此目录执行下列命令。网页和日常求解只读取冻结表，重新提取时才需要加载 OpenSim。

```powershell
python extract.py
python extract.py --verify
```

`--verify` 选取 10 个角度（含网格之间的角度）和 3 个速度，在非零角加速度下，将快速结果与 OpenSim 原生逆动力学、肌肉力臂、满激活主动能力及被动力直接比较。本次 30 组对照的最大绝对差如下。

| 检查量 | 最大绝对差 |
|---|---:|
| 有符号力臂 | 0.000000291 m |
| 被动力 | 0.000320 N |
| 满激活主动能力 | 0.002052 N |
| 空手关节逆动力学力矩 | 2.23 × 10⁻¹⁵ N·m |

上述数值检验的是模型复现误差，不给出个体肌肉张力的测量精度。原始文件或表的 SHA-256 与引擎登记值不同将拒绝载入；更新模型时需要重新提取、独立比对并登记版本。
